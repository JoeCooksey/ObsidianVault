# Research: OSRS Ironman Progression Guide

## Overview

All major sources agree on a four-stage model: **early game** (logistics + quest XP, ~50–100 hrs), **mid game** (Slayer backbone + the "big four" milestones, 100–200 hrs on slayer alone), **late game** (Gauntlet → solo bosses → raids), **endgame** (BiS + capstone capes). The single most-repeated routing rule: quest past slow training early, then let Slayer carry combat while the bowfa grind unlocks everything after.

## Master checklist by stage

### Stage 1 — Early game (→ base ~50s)
- [ ] Quest XP chain: Waterfall, Fight Arena, Tree Gnome Village, Grand Tree, Witch's House (skip low-level melee)
- [ ] Wintertodt → 50+ Firemaking (supplies + cash)
- [ ] Blackjacking → 45–50 Thieving (GP engine)
- [ ] Fairy rings (Fairytale I + II started) · spirit trees · Ardy cloak 1 · graceful
- [ ] Kingdom of Miscellania running (herbs/teaks)
- [ ] Bone Voyage → birdhouse runs · hunter rumours from 46 ([[Varlamore Ironman Unlocks]])
- [ ] 43 Prayer via blessed bone shards · 55 Magic (high alch) · Iban's staff
- [ ] Barbarian fishing 58+ (passive Agility/Strength) · herb runs every login

### Stage 2 — Mid game (→ raid-ready)
- [ ] **Barrows gloves** (full RFD, ~175 QP) — the stage boundary
- [ ] **Fire cape** · **70 Prayer (Piety)** · **Quest cape** (the universal big four)
- [ ] Dragon defender (Atk+Str ≥ 130) · fighter torso · dragon scimitar
- [ ] Moons of Peril sets: Bloodrager (melee/slayer), Eclipse (ranged), Frostweaver (magic)
- [ ] Elite void (Pest Control + Western hard at 70 Ranged)
- [ ] [[OSRS Ironman Slayer Ladder]]: 58 black mask → 85 whip → 87 trident → 91 primordials → 93 occult → 95 lance
- [ ] First zenytes (demonic gorillas) — all 4 eventually
- [ ] 77 Herblore (all quest lamps → Herblore) · 70 Construction · 87 Ranged (chinning)
- [ ] Learner bosses: Scurrius → Sarachnis/Mole → DKs → low-invo ToA

### Stage 3 — Late game (→ raids on farm)
- [ ] Song of the Elves → **camp Corrupted Gauntlet until bowfa + crystal armour** (2 enhanced seeds)
- [ ] Dragon Slayer II → Vorkath · Desert Treasure II → endgame boss foundation
- [ ] Zulrah: blowpipe + swamp trident (~300 KC) · Phantom Muspah: venator bow
- [ ] GWD: Bandos set/BGS, Armadyl set/ACB, Zammy spear/SotD
- [ ] **ToA first** (fang + Lightbearer → 150+ invo → Masori) → **CoX** (Rigour/Augury scrolls, DHCB, ancestral) → **ToB** (Avernic, scythe)

### Stage 4 — Endgame
- [ ] Infernal cape · Dizana's quiver (Colosseum) · sunfire fanatic
- [ ] Mega-rares: twisted bow (CoX), scythe (ToB), Tumeken's shadow (ToA expert)
- [ ] Nex (torva) · Yama *(low confidence)* · Max cape · diary cape

## Key Findings

- The stage boundaries are functional, not arbitrary: Barrows gloves marks early→mid, quest cape + 87 Slayer marks mid→late, bowfa marks late→raids (Sources: all four agree)
- Slayer is the mid-game spine — XP + GP + supplies + gear from one activity (Source: [[Ironman Meta — Progression Guides]])
- The Corrupted Gauntlet is the single highest-leverage grind for an iron: free attempts, and bowfa+crystal trivializes solo ToA, Zulrah, GWD (Source: [[Ironman Efficiency Guide (ironman.guide)]])
- Varlamore restructured the route: bone shards replace expensive prayer training, Moons of Peril fills the quest-gear→Barrows gap, hunter rumours add a passive supply engine (Source: [[Ironman Meta — Varlamore Guide]])
- ToA is the recommended first raid: invocation scaling + the most broadly useful drops (fang, Lightbearer) (Source: [[Ironman Meta — Progression Guides]])

## Contradictions

- [[Ironman Efficiency Guide (ironman.guide)]] pushes 99 Thieving in stage 1.3; [[Ironman Meta — Progression Guides]] treats thieving as "50+ then move on." The Oziris lineage optimizes total-account efficiency (GP/hr early compounds); casual routes defer it. For a normal pace, 50–70 Thieving is enough.
- Black mask at 58 Slayer ([[Ironman Meta — Progression Guides]]) vs "40+ Slayer Cave Horrors" phrasing in the wiki fetch — 58 Slayer is correct for Cave Horrors; treat the 40+ figure as a fetch artifact.
