# Research — Trending GitHub Repositories May 2026

**Research question:** What are the top trending GitHub repositories right now that are most useful to Joe?
**Searches run:** 8
**Sources checked:** GitHub Trending (live), Trendshift, OSSInsight, Medium/ByteByteGo analyses, GitHub topic pages

---

## Key Findings

### 1. GitHub's #1 all-time star count: `build-your-own-x` (504K stars)
`codecrafters-io/build-your-own-x` is the most starred repo on GitHub. It's a curated set of guides for recreating popular technologies from scratch — compilers, databases, shells, neural nets, web servers. This directly aligns with Joe's hands-on build approach. It complements both his Python EE Project Ladder and Karpathy series.

### 2. Karpathy released microgpt in early 2026
A 200-line pure Python project that builds and trains a full GPT from scratch — no dependencies, no framework. Karpathy's most compressed, most educational implementation yet. Joe should work through this after finishing nn-zero-to-hero. It's the natural capstone of the Zero to Hero series.

### 3. AI agent frameworks have taken over the GitHub trending list
5 of the top 20 fastest-growing repositories in May 2026 contain "skills" or "agents" in their name. The top trend is the Claude Code skills ecosystem, with `andrej-karpathy-skills` reaching 151K stars — a repo of CLAUDE.md-format skills based on Karpathy's teaching style.

### 4. Local LLM infrastructure is mainstream
Ollama (165K stars) and Open WebUI (124K stars) together make running a personal, private, free AI assistant trivially easy. Any student can now run LLaMA 3 locally with a single command. Joe can use this for EE homework, paper Q&A, and code review.

### 5. Python EE resources exist and are underused
`PyPedia/Electrical-Engineering-with-Python` provides exactly the circuit analysis + simulation content Joe is building in his Python EE Ladder. Cross-referencing this repo against Joe's 12-project plan could save weeks of design time.

### 6. The quant finance GitHub ecosystem is mature
`wilsonfreitas/awesome-quant` is the definitive curated list. VectorBT is the fastest Python backtesting library. Riskfolio-Lib covers portfolio optimization. These three repos alone cover 80% of the practical tooling in Joe's [[Quant Programming Stack]].

### 7. Workflow automation (n8n) has crossed the mainstream threshold
n8n at 180K stars is now the most-starred self-hosted automation tool. Its native AI agent nodes mean it can chain LLM reasoning with real-world actions. Joe could use it to automate his Obsidian vault workflows or research digests.

### 8. Understand-Anything is a novel learning tool
At 25K stars and climbing fast, it turns any codebase or knowledge base into an interactive knowledge graph. For a student studying complex EE papers and LLM codebases simultaneously, this is a genuine learning multiplier.
