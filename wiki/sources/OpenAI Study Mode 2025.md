# OpenAI Study Mode (2025)

A ChatGPT mode that changes the model's behavior from answer-delivery to guided learning.

## Key Claims
- Study Mode makes ChatGPT **ask questions, request input, test recall, and offer hints instead of full solutions**, supporting active recall, spaced repetition, and metacognition. (confidence: medium)
- It is explicitly designed around established learning strategies: **chunking, retrieval practice, cognitive-load reduction, and distributed learning**. (confidence: medium)
- Stock ChatGPT has **no built-in flashcards, spaced-repetition engine, or practice tests**, and does not work from your course materials unless you paste/upload them each session. (confidence: high — structural limitation)

## Contribution to topic
Validates the prompt-design choices in [[ChatGPT ML Tutor Prompt (Zero to Pro)]]: the Socratic, hint-first, recall-first behavior is the documented effective pattern. Also names the key limitation (no cross-chat memory) the prompt must work around via the paste-the-tracker method.
