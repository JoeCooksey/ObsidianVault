# NerdWallet — Robinhood Review 2026

Brokerage review establishing what index-fund vehicles Robinhood actually supports.

## Key Claims (confidence: high)

- **No mutual funds.** Robinhood offers free stock, ETF, options, and crypto trades — but does not offer mutual funds at all. To hold FZROX/FXAIX/VTSAX-type mutual funds you need a different broker (Fidelity, Vanguard, Schwab).
- **~2,300 ETFs**, including index ETFs and bond ETFs — so you can still fully index on Robinhood using ETFs (VOO, VTI, VXUS, BND, etc.).
- **Fractional shares** let you invest as little as $1 in any ETF, commission-free.

## What It Contributes

Settles the core practical fact for the user's question: **on Robinhood, "index funds" means index ETFs, not mutual funds.** This is the decisive difference from Fidelity. It does not make Robinhood worse for indexing — VOO/VTI/VXUS cover the same ground — but it changes which tickers you buy and removes access to Fidelity's 0.00% ZERO mutual funds.
