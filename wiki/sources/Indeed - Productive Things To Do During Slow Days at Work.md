# Indeed - Productive Things To Do During Slow Days at Work

Practitioner listicle of things to do when work is slow. Useful as a menu of **low-resumption-cost, desk/phone-friendly** options — most items are admin or development tasks you can drop the instant a customer calls.

## Key claims

- Desk/phone-friendly downtime activities: review and edit your own work; read a book / listen to a podcast / watch a webinar (professional development); organize workspace; update resume; network (message a mentor about news, trends, advice); manage and pre-draft email; plan ahead and set goals; help a coworker. (confidence: medium — practitioner advice, not studied)
- A parallel result set ([call-center forums and tip pages](https://callcentertips.com/training-and-development/how-do-you-survive-a-boring-call-center-job/)) adds: practice the agent knowledge base to get faster, study product/industry material, learn a language via an app, discreet desk exercise/stretching. (confidence: low — forum/blog)

## What it contributes to the topic

Confirms that the *conventional* advice for slow jobs is exactly the fragmentation-tolerant set — passive learning, admin, networking, light movement — and tellingly **never** recommends starting genuinely deep work between calls. This matches the [[Interruption Resumption Cost]] science from the other direction.

## Caveats

> [!gap] Practitioner sources, not peer-reviewed. They list options but don't rank them by interruption-tolerance or learning value — that synthesis is added in [[Low-Demand Job Downtime Playbook]].
