# Ben Eater — Build an 8-bit Computer

The iconic capstone breadboard project and the reason "breadboard computer" is a genre. Anchors the top rung of [[Breadboard Project Ladder]] and the showcase in [[Coolest Breadboard Projects]]. See [[Ben Eater]].

## What it contributes
A long, video-paced course that builds a working 8-bit computer entirely on breadboards using **74LS-series TTL logic chips** — no microcontroller, no soldering. The whole machine is broken into understandable modules (clock, A/B registers, ALU, bus, SRAM, program counter, instruction register, microcoded control logic, 7-segment output). Famous offshoots: a breadboard build that **plays Snake on a small display**, and a from-scratch **VGA / world's-worst video card**.

Why it matters for an EE: it converts the abstract "how does a CPU work" into wires you place by hand — the single best bridge between [[Digital Logic and Boolean Algebra]] and real computer architecture.
