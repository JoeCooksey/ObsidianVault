# Starting Electronics — Beginner's Tools

Tool-list reference for [[Breadboard Starter Kit (What You Need)]].

## What it contributes
Separates the **must-have-now** tools from the **buy-later** ones for a breadboard beginner:
- **Now**: breadboard, jumper wires, a multimeter (DMM), wire strippers/cutters, a 5 V/9 V power source, and the component grab-bag (resistors, LEDs, caps, transistors, a 555).
- **Later**: a soldering iron + solder, solder sucker / braid, helping-hands — needed only when you graduate from breadboard to perfboard/PCB.

The key beginner insight repeated across tool guides: **solderless breadboarding deliberately removes the soldering iron from the critical path**, so the entry cost and skill barrier are low.
