# Matrix Theory in Wireless Communications (MDPI Algorithms 2016)

Peer-reviewed overview paper (*Algorithms*, 2016) on matrix theory applications in wireless communications and signal processing.

## What It Contributes

- **MIMO via SVD**: singular value decomposition of the channel matrix yields orthogonal input-output channels over which independent streams transmit without inter-channel interference — the math behind multi-antenna Wi-Fi/5G capacity gains.
- **OFDM via DFT**: orthogonal frequency division multiplexing uses DFT/IDFT matrix operations to reduce receiver complexity; the DFT is fundamentally a matrix transform.
- **General framework**: filtering, modulation, PCA/SVD feature extraction all sit on linear algebra.
