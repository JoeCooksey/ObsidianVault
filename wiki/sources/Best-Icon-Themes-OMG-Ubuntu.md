# 8 Best Icon Themes for Ubuntu & Linux Mint (OMG! Ubuntu)

Curated icon-theme roundup from a long-running Ubuntu/Linux publication.

## What it contributes
Concrete, install-ready icon recommendations: (Source: this page)

| Theme | Style | Install |
|---|---|---|
| Papirus | Colorful, very complete, active | PPA `ppa:papirus/papirus` → `papirus-icon-theme` |
| Numix Circle | Circular, broad app coverage | PPA `ppa:numix/ppa` → `numix-icon-theme-circle` |
| Qogir | Flat, professional (Arc/Faba/Tela lineage) | GNOME-Look → `~/.icons` |
| WhiteSur | macOS Big Sur style | GNOME-Look → `~/.icons` |
| Vimix | Multiple color variants + matching GTK | GNOME-Look → `~/.icons` |
| We10X | Windows "fluent" style | GNOME-Look → `~/.icons` |
| Obsidian | Faenza continuation, glossy/tiled | GitHub → `~/.icons` |
| Newaita | Modern, intricate, optional dark | GitHub → `~/.icons` |
