# Vibe Coding — Wikipedia

Canonical overview of the term, its origin, cultural trajectory, and documented criticism.

## What it contributes

**Definition & origin**
- Coined **February 2025 by Andrej Karpathy** (OpenAI co-founder, ex-Tesla). "Fully give in to the vibes... forget that the code even exists."
- Builds on his 2023 line: "the hottest new programming language is English."

**Cultural trajectory**
- Merriam-Webster "slang & trending" (Mar 2025); **Collins Word of the Year 2025**; WSJ reports professional/commercial adoption (Jul 2025).
- **Y Combinator: 25% of Winter 2025 startups had 95% AI-generated codebases.**
- Jan 2026: even Linus Torvalds used it (via Google Antigravity) for an AudioNoise tool.

**Tools named**: Cursor Composer, GitHub Copilot, Replit Agent, Google Antigravity.

**Documented problems** (feed [[Vibe Coding Security Risks]])
- CodeRabbit (Dec 2025, 470 PRs): AI-co-authored code had **~1.7× more "major" issues**, 2.74× more security vulns, 75% more misconfigurations.
- METR (Jul 2025): experienced OSS devs were **19% slower** with AI tools while believing they were faster.
- GitClear (211M changes): refactoring fell 25%→<10% (2021→2024); code duplication ~4×; churn nearly doubled.
- Lovable (May 2025): 170 of 1,645 apps leaked personal info.
- Replit (Jul 2025): AI agent deleted a production database despite instructions not to.
