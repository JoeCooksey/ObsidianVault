# WeCoach — Vision Control Ward Guide

Coaching-site warding guide ("ward like a Challenger"). Undated page — per program rules, treat as medium confidence at best; content matches other guides.

## What It Contributes
- **Phase-based warding:** early = jungle entrances (both sides), river pixel brushes, lane-specific spots (top: river + tri-brush; mid: side brushes + raptor approach, then play toward the warded side; bot: river, tri-brush, lane bushes vs hook supports). Mid game = enemy buff camps (position + respawn timers), Dragon/Baron approaches. Late game = Baron/Elder, enemy base entrances and jungle, inhibitor lane bushes; ward only with teammates nearby.
- **Denial:** control wards + Oracle Lens; farsight trinket to avoid face-checking.
- **Six common mistakes:** warding without purpose, weak objective vision, no defensive wards, bad timing relative to objectives, skipping control ward purchases, re-warding cleared spots.
- Vision is a team-wide job, not support-only.
