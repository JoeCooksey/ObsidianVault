# Source - edX Is a Master's in EE Worth It

edX resource page citing BLS data on the value of a master's in electrical engineering.

## What It Contributes

- **Earnings gap (BLS 2024):** master's median weekly $1,840 vs. bachelor's $1,543 — ~$15,500/yr.
- **EE median salary:** $111,910 (May 2024). Top industry: aerospace product/parts manufacturing at $136,570.
- **Growth:** 9% projected 2023–2033, double the all-occupations average.
- **Cost/time:** 1–3 yrs; ~$21,072/yr on-campus, ~$13,688/yr online (2020 data).
- **Why worth it:** higher pay; specialization into signal processing, power systems, AI; qualifies for lead engineer / engineering manager / R&D lead; enables pivots to renewables, biomedical, telecom.

## Reliability Note

Marketing-adjacent (edX sells courses) but the core salary/growth figures are sourced to **BLS**, which is authoritative — those carry `high` confidence. Did not discuss downsides, so balance with [[Source - EE PhD vs MS Industry Value]].
