## 3. How to add a job (30 seconds)
1. Copy `_templates/Job.md` into `wiki/jobs/` (or duplicate the EXAMPLE note).
2. Fill `company`, `role`, `url`, set `status: interested`, `fit:`, and a `follow_up_date`.
3. It shows up in the tracker automatically.

## Status values
`interested` → `applied` → `interviewing` → `offer` / `rejected` / `closed`

## ⚠️ Note on auto-applying
Automated mass-applying violates Indeed/LinkedIn ToS and risks an account ban — and generic applications get filtered out. This system automates the slow parts (finding + writing tailored applications) while keeping you in control of the click. Targeted beats bulk, every time.
