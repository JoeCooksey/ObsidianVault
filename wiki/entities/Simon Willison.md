# Simon Willison

Veteran software engineer and writer; co-creator of the Django web framework and creator of Datasette. One of the most cited practitioner voices on responsible LLM-assisted development.

## Significance to this topic

- Drew the **sharpest definitional line** around vibe coding: it means "building software with an LLM **without reviewing the code it writes**." (Source: [[Not All AI-Assisted Programming Is Vibe Coding]])
- His distinction: *"If an LLM wrote the code for you, and you then reviewed it, tested it thoroughly and made sure you could explain how it works to someone else — that's not vibe coding, it's software development."*
- **Golden rule**: "I won't commit any code to my repository if I couldn't explain exactly what it does to somebody else."
- Argues vibe coding is great for **low-stakes, throwaway, sandboxed** work and for democratizing programming — but not for production, security-sensitive, or private-data code.

## Why Joe cares

Willison's frame separates "vibe coding" (fast, disposable) from "AI-assisted engineering" (reviewed, durable). For someone building real projects, this is the line between a weekend toy and something you can sell or put on a resume. Connects to [[Programming Skills AI Cannot Replace]].
