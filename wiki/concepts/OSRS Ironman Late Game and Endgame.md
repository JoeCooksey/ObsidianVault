# OSRS Ironman Late Game and Endgame

Quest cape → raids → best-in-slot. The defining late-game grind for irons is the **Corrupted Gauntlet**: bow of Faerdhinen + crystal armour carries an iron through nearly all subsequent PvM, and attempts cost nothing. The efficiency route's literal instruction: "camp Corrupted Gauntlet until 2 enhanced weapon seeds" (Source: [[Ironman Efficiency Guide (ironman.guide)]]).

## Unlock checklist

### Gateway quests
- [ ] **Song of the Elves** → Priffdinas, Gauntlet
- [ ] **Dragon Slayer II** → Vorkath, Myths' Guild, ava's assembler
- [ ] **Desert Treasure II** → Ancient sceptre line, DT2 bosses; "foundation for endgame bossing mechanics"
- [ ] Beneath Cursed Sands → ToA

### The Gauntlet block
- [ ] Learn regular Gauntlet → Corrupted Gauntlet
- [ ] **Bow of Faerdhinen (bowfa)** — enhanced seed #1
- [ ] Crystal armour set (+ second enhanced seed per the route)

### Solo boss gear circuit
- [ ] Zulrah — toxic blowpipe, trident of the swamp, serpentine helm (~300 KC for full uniques)
- [ ] Demonic gorillas — all 4 zenytes: anguish, torment, suffering, tortured bracelet
- [ ] 95 Slayer → Alchemical Hydra → **Dragon hunter lance**
- [ ] 91 Slayer → Cerberus → **primordial boots** (+ pegasian, eternal crystals)
- [ ] Phantom Muspah — venator bow, ancient sceptre
- [ ] Vorkath — sustained GP/supply boss
- [ ] God Wars Dungeon: Bandos set + BGS (Graardor), Armadyl set + ACB (Zilyana area), Zamorakian spear / staff of the dead (K'ril)

### Raids (recommended order)
- [ ] **ToA first** — most ironman-friendly, scalable invocations; priority drops: Osmumten's fang, Lightbearer; push 150+ invo for Masori (fortified with Armadyl pieces)
- [ ] **CoX** — dexterous + arcane prayer scrolls (**Rigour/Augury**), dragon hunter crossbow, ancestral, eventually twisted bow
- [ ] **ToB** — Avernic defender, scythe of Vitur; hardest, team-dependent

### Capstones
- [ ] Infernal cape (Inferno)
- [ ] Fortis Colosseum — sunfire fanatic armour (Wave 4+), **Dizana's quiver** (BiS ranged back) on completion (~95 Atk/Str, 90 Def, 94 Magic for Wave 12)
- [ ] Mega-rares: twisted bow (CoX), scythe (ToB), Tumeken's shadow (expert ToA)
- [ ] Nex (torva, zaryte crossbow), Yama *(low confidence — endgame boss named in 2026 sources, no details fetched)*
- [ ] Max cape · Achievement diary cape

## Stage logic

Bowfa+crystal makes ToA solo "very doable"; ToA funds the rest. Raid order beyond ToA depends on team availability and which BiS piece unblocks the most content (Source: [[Ironman Meta — Progression Guides]]).
