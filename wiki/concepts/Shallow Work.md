# Shallow Work

**Definition (Newport):** Non-cognitively demanding, logistical-style tasks, often performed while distracted. These efforts tend not to create new value in the world and are easy to replicate.

Shallow work is the contrast to [[Deep Work]]. It is not inherently bad — some shallow work is necessary — but its insidious quality is that it *feels* productive while crowding out the work that actually creates value.

## Examples by Category

| Category | Shallow Examples |
|---|---|
| Communication | Answering routine emails, Slack notifications, status updates |
| Meetings | Unproductive check-ins, unnecessary standups |
| Admin | Filling forms, logging timesheets, scheduling |
| Social media | Scrolling, posting, monitoring likes |
| Coordination | Following up on other people's actions |
| Passive reading | Reading articles without synthesis |

## Why Shallow Work Dominates

- Easily measured and visible — *looks* like work
- Satisfies social/organizational obligations
- Low cognitive cost — easy to do when tired or distracted
- Provides dopamine spikes (email badge, Slack reply)
- Lacks urgency/scheduling, so it fills every available gap

## The Shallow Work Creep Problem

Knowledge workers default to shallow work because:
1. No clear signal for when deep work should happen
2. Organizations reward *responsiveness* over *output quality*
3. The 23-minute recovery cost of each interruption is invisible

## Minimizing Shallow Work

- **Batch processing** — answer email in two daily 30-minute blocks only
- **Delegate or automate** — identify what an AI agent can handle
- **Flat-out ignore** — Newport recommends most shallow obligations can simply be dropped with minimal real consequence
- **Time audit** — Newport's 1-week 15/30-min block audit reveals how much time shallow work is actually consuming
