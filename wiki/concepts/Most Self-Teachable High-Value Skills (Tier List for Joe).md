# Most Self-Teachable High-Value Skills (Tier List for Joe)

What Joe should self-teach, ranked by **usefulness × self-teachability**. The ranking is derived by applying the science of learning ([[Research: How to Learn Anything (The Science of Learning)]]) as a *selection filter*, not just a study method.

## The selection filter

The evidence-based techniques only work when you can run them **solo**. So a skill is highly self-teachable when it has three properties:

1. **A built-in feedback loop** — something tells you instantly when you're wrong, so you don't need a human coach. [[Deliberate Practice]] requires fast feedback; if the skill *supplies its own*, you can self-teach it to a high level.
2. **Free, world-class resources** — so [[Metalearning (Drawing the Map)]] can find a proven path.
3. **Clean deconstruction** into sub-skills you can drill ([[Rapid Skill Acquisition (First 20 Hours)]]).

> [!warning] What NOT to self-teach
> Skills that *lack* a feedback loop — public speaking, design taste, leadership, negotiation — need a coach or an audience. They are poor pure-self-teaching targets and should be learned through reps with real people, not alone.

Applied to Joe's profile (1st-year EE → wide-bandgap power electronics, strong programmer, AI-agent builder, investor), the filter produces:

## Tier S — highest useful × most self-teachable

| Skill | Feedback loop | Why it's top for Joe |
|---|---|---|
| **Math foundations** (linear algebra → calculus → differential equations) | Problem sets with answer keys | The single highest-leverage target. Fills the vault's **empty Math domain**, **double-dips with EE coursework**, and is the substrate of AI, quant, and signal processing. → [[Linear Algebra for AI and Quant]], [[Calculus in Electrical Engineering]], [[Differential Equations in Electrical Engineering]] |
| **Programming depth** (Python, then C/C++) | The interpreter/compiler — the *tightest feedback loop that exists* | Already a strength; deepening it compounds everything else (AI, EE automation, quant). → [[Python EE Project Ladder]], [[C++ Self-Teaching Roadmap for EE]] |
| **AI/ML fundamentals + context engineering** | Code runs or it doesn't; training loss falls or it doesn't | S-tier usefulness, fully self-teachable (Karpathy, fast.ai — free), and it sits at *Joe's* EE×AI intersection. → [[Context Engineering]], [[AI Skills Roadmap for Electrical Engineers]] |

## Tier A — strong, self-teachable, career-specific

| Skill | Feedback loop | Note |
|---|---|---|
| **Circuit simulation (LTSpice)** | The simulation result | Instant-feedback gateway to the WBG/power-electronics track. → [[LTSpice Complete Skills Guide]] |
| **Verilog / FPGA** | HDLBits + self-checking testbenches grade you automatically | ~$175k average salary, a direct Sandia/LLNL path, and HDLBits is *designed* for retrieval practice. → [[Verilog and FPGA Learning Path]] |
| **Investing / financial literacy** | The market + a spreadsheet | Lower skill-depth, but it *literally* compounds and reaches "good enough" fast. → [[Financial Literacy Roadmap]], [[Index Fund Investing]] |

## Tier B — fast wins / watch

- **Touch typing, Git, Linux** — knock out in days; high daily-use multiplier. → [[Zero Cost Computer Skills — Tier List]]
- **Physical AI / robotics** — highest *ceiling* item, but lower early self-teachability (needs hardware; sim has a learning curve). Start **sim-first**. → [[Physical AI Build Guide (Roadmap for Joe)]]

## How to run any of them (the protocol)

1. **Map first** (~10% of time): split the subject into Concepts (understand), Facts (memorize), Procedures (practice). → [[Metalearning (Drawing the Map)]]
2. **Facts → [[Spaced Repetition|Anki]]**; **Concepts → [[The Feynman Technique]]**; **Procedures → do problems / build projects closed-book** ([[Active Recall (Retrieval Practice)]]).
3. **[[Interleaving (Learning)|Interleave]]** problem types and **expect it to feel hard** — that's the signal it's working ([[Desirable Difficulties]]).
4. **Compound daily** — a small protected block beats marathons. → [[Compound Time (5-Hour Rule)]]

## The one-line answer

> [!tip] If Joe self-teaches *one* thing
> Make it **math foundations**. It is the only item that simultaneously fills his biggest gap, accelerates his degree, and underpins both the AI and quant directions he leans toward — and it is fully self-teachable because problem sets give their own feedback.
