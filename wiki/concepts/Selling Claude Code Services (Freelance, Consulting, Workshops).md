# Selling Claude Code Services (Freelance, Consulting, Workshops)

The **services** ladder for someone skilled with [[Claude Code loop Command|Claude Code]]. You're not selling AI access — you're selling shipped deliverables and infrastructure a client keeps. Four offerings, increasing in price and effort. (Source: [[How to Make Money with Claude Code — youcanbuildthings 2026]])

## 1. Freelance development — $50–$300/hr

- Code 10× faster; a 2-week ($6K) job ships in ~8 hours, so effective rate skyrockets.
- Deliverable: working code **+ a configured `.claude/` directory** the team keeps.
- Sales move: **"Don't tell a client you use AI — show them a live build."** A 10-min demo beats any rate justification.
- Entry effort: **low** (if you already code). Best starting rung.

## 2. Fixed-scope consulting — $5,000–$15,000 / engagement

- 3–5 days of work. You set up a team's AI-dev workflow.
- Deliverable: a **config package** — `CLAUDE.md`, `settings.json`, custom slash commands, `SECURITY.md`, hooks, and team training.
- Pricing rule: **"Price the engagement, not the hour."** Fixed price → faster approval, higher effective day-rate.

## 3. Workshops & training — $3,000–$8,000 / half-day

- Live 4-hour session for 8–15 developers.
- Deliverable: curriculum + hands-on training.
- Funnel: build authority with **free content first**, then sell workshops + self-paced courses ($49–$99).

## 4. Micro-SaaS (product, not service)

- The graduation from services to assets — covered in [[Profitable Micro-SaaS Playbook]]. Recurring revenue, no client management, but you own distribution.

## The principle that ties it together

> [!quote] "The premium is the deliverable, never the AI." Companies pay for configured infrastructure they retain and results they can't get elsewhere — not for the fact that you typed into a terminal.

## Sequencing for Joe

Freelance (cash + portfolio) → publish the work ([[Building in Public]]) → consulting/workshops once you have a public track record. Beyond solo, the agency model scales this → [[AI Automation Agency]].
