# Compounding Daily Projects Tier List

Options for **long-term projects Joe can touch a little every day** so they accrue into a durable asset. Ranked by *compounding ROI*, not by how impressive they sound.

## Ranking lens

A project earns a high tier when it scores on all four axes:

1. **Asset durability** — does today's work still pay off in 5 years? (A skill and a code repo do; a streak of likes does not.)
2. **Leverage type** — labor < capital < **code/media** (permissionless, replicate at zero marginal cost). (Source: [[Permissionless Leverage]])
3. **Trajectory fit** — does it pull toward Joe's actual target: WBG power electronics → LLNL/Sandia? (Source: [[EE High Income Action Plan]])
4. **Low activation energy** — can it survive a bad day at a 5-minute floor? Streaks die when the daily bar is too high. (Source: [[Sustainable Daily Practice (Streak Design)]])

> [!note] The meta-principle
> The best daily project is one that is *simultaneously* skill practice **and** a public artifact **and** career evidence. Stack the three and one hour of daily work pays you three times. The S-tier picks all do this.

## S-Tier — start now, compounds hardest

- **GitHub engineering log (build-in-public portfolio).** Commit something small to a real EE/Python project most days. This is code leverage + the #1 hiring evidence LLNL/Sandia can actually *see*. A green contribution graph is a 4-year proof-of-consistency artifact. Already scaffolded: [[Python EE Project Ladder]], [[EE Freshman Portfolio Strategy]]. *Daily floor: one commit, even a README line.* (Source: [[Building in Public]])
- **Personal knowledge base / second brain (this vault).** Joe is already running it. It compounds into **specific knowledge** — the non-credential edge that escapes competition (Source: [[Permissionless Leverage]]) — and it becomes the raw material for everything in the A-tier (blog posts, video scripts, project ideas). *Daily floor: one note or one ingest.* See [[Reading Application Framework]].
- **Index-fund investing (automated DCA).** The only item here that is *literally* compound interest. $200/mo from age 19 → ~$1.87M at 65; same amount started at 35 → $372k. The "daily work" is near-zero after setup, which is the point — it runs while he sleeps. (Source: [[Index Fund Investing]], [[Financial Literacy Roadmap]])

## A-Tier — start within a month

- **Technical writing / learn-in-public blog.** Write up what he's learning (WBG devices, LTSpice, FPGA). Permissionless **media leverage**: written once, read forever. Compounds three ways — clarifies his own thinking, builds reputation, and is **career capital** that makes specialization legible. Dev.to/blog authors report mentoring offers, talks, and hiring interest from consistent small posts. (Source: [[Building in Public]])
- **Open-source contributions.** "One merged PR to a real project > five solo clone projects" — it proves he can read an unfamiliar codebase, follow conventions, take review, and ship. Targets: KiCad, ngspice, cocotb ecosystem. Reputation rises per merge; maintainers get recruited by teams using their library. (Source: [[Building in Public]])
- **Deliberate practice of one high-income skill.** Pick the core craft (Python → FPGA/Verilog or power-electronics design) and grind it daily at the edge of ability. 15 min/day = 62.5 hr/year = **312 hr over 5 years** — more focused practice than most professionals log post-degree. (Source: [[Compound Time (5-Hour Rule)]], [[High Income Skills Tier List]])

## B-Tier — strong, supporting

- **Daily reading habit.** Compounds into mental models and writing fuel; already a Joe habit. Lower tier only because it's *input*, not a public asset on its own — pair it with the knowledge base to upgrade it. (Source: [[Benefits of Reading]], [[Reading Retention Methods]])
- **YouTube / video explainers.** Highest media-leverage ceiling, but 6–18 month traction lag and high per-unit time cost. Best as a *downstream* of the blog + knowledge base, not a cold start.
- **A real indie tool/product.** Build something that solves an actual EE pain (a calculator, a SPICE helper, a converter-design app). Higher variance, but a shipped product is the purest "earns while you sleep" asset. (Source: [[Permissionless Leverage]])
- **Relationship / network compounding.** Long-term games with long-term people; light daily "pinging." Reputation and trust compound over decades. (Source: [[Generosity-First Networking]], [[Pinging System]])

## C-Tier / Avoid

- **Content for vanity metrics with no underlying craft.** Likes don't compound; skill and owned assets do.
- **Get-rich-quick "passive income" funnels** (dropshipping, crypto bots, day trading). Consistent with the D-tier of [[Online Income Methods Tier List]] — negative-EV, no career capital.

## Joe's recommended stack (don't do all of them)

Pick **two compounders + the automated one**: (1) GitHub engineering log, (2) a learn-in-public blog fed by this vault, (3) automated index-fund DCA running in the background. That's one durable code asset, one durable media asset, and one durable capital asset — all three leverage types covered, ~30–45 min/day total, each surviving a 5-minute floor on bad days.
