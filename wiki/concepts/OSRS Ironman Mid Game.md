# OSRS Ironman Mid Game

From base ~50s to raid-ready. Slayer is the backbone — it pays out combat XP, GP, supplies, and the gear ladder simultaneously; expect 100–200 hours on the slayer ladder alone (Source: [[Ironman Meta — Progression Guides]]). Four universal objectives anchor the stage: **Barrows gloves, fire cape, 70 Prayer (Piety), quest cape**.

## Unlock checklist

### The big four
- [ ] **Barrows gloves** — full Recipe for Disaster (~175 QP); BiS gloves for nearly everything; the early→mid boundary marker
- [ ] **Fire cape** — TzHaar Fight Cave; first real PvM test
- [ ] **70 Prayer** — Piety (bone shards or ensouled heads)
- [ ] **Quest cape** — "unlocks everything": Prif (Song of the Elves), all diaries, every teleport

### Melee
- [ ] Dragon defender — Warriors' Guild (Attack + Strength ≥ 130)
- [ ] Fighter torso — Barbarian Assault
- [ ] Helm of Neitiznot (Fremennik Isles) → slayer helm later
- [ ] Dragon scimitar (Monkey Madness I)
- [ ] Blood Moon (Bloodrager) set — [[Varlamore Ironman Unlocks|Moons of Peril]], 75+ combat; strong for Slayer, stepping stone to Bandos
- [ ] Abyssal whip — 85 Slayer
- [ ] Barrows sets (Dharok's, Guthan's, Karil's, Ahrim's); Hard Morytania diary first (+50% bonus runes)

### Ranged
- [ ] Range void → **elite void** (Pest Control; elite needs Western hard diary at 70 Ranged)
- [ ] Eclipse Moon set (Moons of Peril) as an iron-friendly mid ranged set
- [ ] Black d'hide (hard clues) as fallback
- [ ] Ranged 60 → 87 (chinning) per the efficiency route

### Magic
- [ ] Iban's → Trident of the seas (87 Slayer, Kraken)
- [ ] Blue Moon (Frostweaver) set (Moons of Peril)
- [ ] Lunar Diplomacy + Dream Mentor (Lunar spellbook, Magic XP)
- [ ] Occult necklace — 93 Slayer (Smoke Devils)

### Slayer ladder
See [[OSRS Ironman Slayer Ladder]]: 58 black mask → slayer helm (i) → 75 → 85 → 87 → 91 → 93 → 95.

### Skill targets (post-gloves route)
61 Crafting · 70 Mining · 65→70 Atk/Str · 70 Agility · **77 Herblore** (all quest lamps → Herblore until 77) · 70 Construction · 70 WC/Smithing (Source: [[Ironman Efficiency Guide (ironman.guide)]])

### Mid bosses to learn
Scurrius → Giant Mole / Sarachnis → Dagannoth Rex (Berserker ring) → demonic gorillas (first zenyte) → low-invocation ToA after Beneath Cursed Sands.

## Exit criteria

Gloves + fire cape + quest cape, 87+ Slayer, first zenytes, elite void, 77+ Herblore → [[OSRS Ironman Late Game and Endgame]].
