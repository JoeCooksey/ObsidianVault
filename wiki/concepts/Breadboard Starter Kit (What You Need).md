# Breadboard Starter Kit (What You Need)

Everything required to start building breadboard circuits, split into **buy-now** (≈$40–70 total, or one bundled kit) and **buy-later**. The beautiful part: **no soldering iron needed** to start — solderless breadboarding removes it from the critical path (Source: [[Starting Electronics — Beginner's Tools]]).

## Tier 1 — The non-negotiables

| Item | What/why | Notes |
|---|---|---|
| **Breadboard** | 830 tie-point full-size is the standard | [[How a Breadboard Works]]; get 1–2 |
| **Jumper wires** | pre-cut M-M kit (~140 pcs, multi-color) + flexible M-M/M-F | color helps trace nodes |
| **Power source** | 5 V / 3.3 V — borrow from a [[Raspberry Pi Pico\|Pico]]/Arduino, a benchtop supply, a breadboard power module, or 4×AA (6 V) | start with a USB-powered module |
| **Multimeter (DMM)** | measure voltage, current, resistance, continuity | the #1 measuring tool; digital > analog |
| **Component grab-bag** | resistors (assorted), LEDs, capacitors (ceramic + electrolytic), pushbuttons, a [[555 Timer IC]], a few NPN transistors (2N2222/BC547), diodes | a bundled "starter kit" covers all of this |
| **Hand tools** | wire strippers/cutters, small needle-nose pliers, small screwdrivers | |

> [!tip] The fastest path: buy **one bundled electronics starter kit** (breadboard + jumpers + resistor/LED/cap/IC assortment in a box, ~$25–40) and add a **multimeter** separately. That single purchase covers Tier 1 except the meter.

## Tier 2 — The "brains" (when you want logic/sensors)
- A **microcontroller**: [[Raspberry Pi Pico]] (~$4, breadboardable, MicroPython) or an Arduino Uno/Nano (largest tutorial ecosystem).
- A sensor/module assortment: photoresistor (LDR), potentiometers, temperature sensor, ultrasonic distance, small servo, piezo buzzer, shift register (74HC595), decade counter (4017).
- A **bench DC power supply** (adjustable, current-limited) once you outgrow USB/battery.

## Tier 3 — Buy-later (permanent builds)
- **Soldering iron + solder**, solder sucker / braid, flux.
- Perfboard / protoboard to make a breadboard circuit permanent.
- Helping-hands, magnifier, anti-static wrist strap, safety glasses.

## What you do NOT need yet
- A soldering station (breadboard = solderless).
- An oscilloscope (nice for analog/audio later; not for first LED circuits).
- Expensive name-brand parts — generic resistors/LEDs are fine to learn on.
