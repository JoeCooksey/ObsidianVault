# Udemy Personal Plan EE Coverage Map

Verified 2026-07-27 by browser audit of the "Premium" badge (Source: [[Udemy Catalog Audit — EE Topics, Premium Badge Method (July 2026)]]). ✅ = in the plan, ❌ = must be bought separately. Ratings shown as `stars (reviews) hours`.

## Coverage verdict by track

| Track | Verdict |
|---|---|
| Embedded / firmware | ⭐ **Excellent** — the strongest EE track in the plan |
| PCB & hardware design | ⭐ **Excellent** — including the 112-hour flagship |
| MATLAB / Simulink | ⭐ **Excellent** |
| Electrical power systems | **Strong** — deep 20–35 h courses |
| Control systems | **Good** |
| Power electronics | **Adequate** — one great core course, thin above it |
| VLSI / ASIC | **Partial** — verification & DFT yes, physical design mostly no |
| FPGA / HDL | **Weak** — 6 of 17 top results |
| **LTspice** | **Absent** — 1 of 17, and it isn't really an LTspice course |
| **WBG device physics (SiC/GaN)** | **Absent as a topic** — only a chapter inside one course |
