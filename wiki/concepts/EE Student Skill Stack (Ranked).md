# EE Student Skill Stack (Ranked)

> The full-degree view of what to learn, ranked by leverage. The freshman-specific version lives in [[Research - First-Year ASU EE Skills]]; this page ranks skills across all four years and folds in the 2026 frontier (AI, WBG power). Match the tier to where you are.

## The One-Line Answer
The single highest-leverage skill in EE is **deep math fluency**, because it gates every downstream subject. After that, the stack is: **circuit intuition → one strong programming language → lab-tool fluency → a chosen specialty → soft skills that ship the work.** (Source: [[Research.com — Most Valuable EE Degree Skills]], [[Siemens — 7 In-Demand EE Skills]])

## Tier S — Foundational (gates everything; build first)
- **Math as a tool, not a grade** — calculus, differential equations, linear algebra, complex numbers. EE *is* Fourier/Laplace/phasors; weak math = a wall at Circuits and Signals. (Source: [[Research - First-Year ASU EE Skills]])
- **Circuit analysis & intuition** — KVL/KCL, Thevenin, RC/RL/RLC, op-amps. The literacy the whole field is built on. (Source: [[Research.com — Most Valuable EE Degree Skills]])
- **One programming language, fluently** — Python first (data, scripting, signal processing); C/C++ for embedded. "Programming proficiency" is named in every 2026 skills survey. (Source: [[Research.com — Most Valuable EE Degree Skills]])

## Tier A — Practitioner (separates candidates in interviews)
- **Lab-tool fluency** — multimeter → breadboard → oscilloscope → function generator. The three instruments every EE must own by junior year. (Source: [[Research - First-Year ASU EE Skills]]) See [[How a Breadboard Works]].
- **SPICE simulation** — LTspice (free, industry-standard); learn before Circuits I.
- **MATLAB** — the controls/signals/DSP standard; required upper-division.
- **Git/GitHub** — non-negotiable by sophomore year; turns coursework into a visible portfolio.
- **Embedded / microcontrollers** — Arduino → STM32 → [[Raspberry Pi Pico]]. Bridges theory to real systems; best freshman portfolio builder.
- **CAD/PCB design** — KiCad (free) or Altium; "CAD tools" listed by ~110k engineers. (Source: [[Siemens — 7 In-Demand EE Skills]])

## Tier B — Specialty (pick one to go deep, junior+ year)
- **Control systems** — ~69% job-growth signal; the math-heavy, high-demand core. (Source: [[Siemens — 7 In-Demand EE Skills]])
- **Power electronics / WBG** — SiC/GaN, EV inverters, data-center power. Joe's chosen track; highest 2025–2026 demand.
- **Signal processing / RF / communications** — DSP, FFT, modulation, antennas.
- **Digital design / FPGA** — Verilog/VHDL, Vivado/Quartus.
- **ML / AI for hardware** — edge inference, the EE×AI intersection. See [[Research - Most Useful Topics to Learn Now (for Joe)]], [[Physical AI (Embodied Intelligence)]].

## Tier C — Multipliers (cheap to start, compound forever)
- **Communication & teamwork** — ranked the **#1 skill** by >90% of employers, ahead of any specific tool. Write a clear technical email; present a lab result; document a project in plain English. (Source: [[Siemens — 7 In-Demand EE Skills]])
- **Reading & self-teaching** — the meta-skill that makes every other tier learnable from a book. This is where the [[Fiction Roadmap for EE Skills (Sci-Fi to Skill Map)]] and [[Self-Study Textbook List + NotebookLM Prompt]] come in.

## The Honest Ranking Rule
> [!tip] If short on time, the order is: **math → circuit intuition → Python → lab tools → Git → one specialty → communication.** Everything below math is replaceable; math is not.
