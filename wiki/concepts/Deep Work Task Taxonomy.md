# Deep Work Task Taxonomy

A tiered ranking of tasks by how much they benefit from [[Deep Work]] sessions. S-tier tasks produce disproportionate returns from focused time. F-tier tasks are [[Shallow Work]] — no deep focus required, often better batched or eliminated.

## Classification Criteria

A task ranks higher on this taxonomy when it is:
1. **Cognitively demanding** — pushes working memory and reasoning to the limit
2. **Value-creating** — the output is hard to replicate and improves skills or produces assets
3. **Concentration-dependent** — interruption causes severe quality degradation, not just slowdown
4. **Non-automatable** — cannot be done adequately by AI or routine delegation

## S-Tier — Maximum Deep Work Return

These tasks produce their most valuable output *only* in sustained deep focus. Even a single interruption can destroy the work of a 30-minute session.

| Task | Why S-Tier |
|---|---|
| **Hard problem sets** (math, physics, circuits) | Multi-step reasoning; losing the thread means restarting; the struggle itself builds capability |
| **Original research / synthesis** | Connecting disparate sources into a coherent framework requires holding many things in working memory simultaneously |
| **Writing first drafts** (essays, technical reports) | Requires sustained coherent thought; editing mode and drafting mode are cognitively incompatible |
| **Coding — architecture / algorithm design** | Systems-level thinking requires keeping the entire design space in mind; context rebuilding after interruption = 23 min |
| **Learning a fundamentally new concept** | First-encounter learning requires the deepest encoding; [[Neuroplasticity and Habit Formation]] demands focused repetition |
| **Proof construction** (math, formal logic) | One broken chain of inference invalidates the whole; strict attention required |
| **Design work** (PCB layout, circuit design, LTSpice) | Component-level decisions cascade; restoring design context after distraction is very slow |

### Joe-Specific S-Tier
- MAT 343 problem sets and MATLAB proofs
- EEE 202 circuit analysis problems (nodal/mesh, Laplace)
- PHY 131 derivations and E&M problem sets
- [[Python EE Project Ladder]] coding sessions (new phases)
- [[Buck Converter LTspice Simulation]] design runs
- Research synthesis (wiki ingests, reading technical papers)

## A-Tier — High Deep Work Return

High value, but slightly more recoverable from interruption than S-tier. Still require 60–90 minute uninterrupted blocks.

| Task | Why A-Tier |
|---|---|
| **Strategic planning** | Long-horizon thinking requires sustained focus but is slightly more modular |
| **Complex data analysis** | Pattern recognition in data; recoverable from short interruption with notes |
| **Reading technical textbooks** (active, annotated) | Slow comprehension requires focus, but a bookmark + margin notes allow restarting |
| **Complex debugging** | Systematic hypothesis testing; context partially reconstructable from logs |
| **Learning a programming language** (structured exercises) | Requires attention but has natural stopping points at exercises |
| **Editing / revision** (own writing) | Lower stakes than drafting; editing mode can re-engage faster |

---

## B-Tier — Moderate Deep Work Return

Benefit from 45–60 minute uninterrupted sessions but don't require the full deep work protocol.

| Task | Why B-Tier |
|---|---|
| **Reading non-fiction books** (active) | Benefits from focus but section breaks provide natural stopping points |
| **Preparing presentations** | Modular slides reduce cognitive loss from interruption |
| **Memorization / Anki review** | Spaced repetition is naturally chunked; benefit from focus but short sessions work |
| **Creative brainstorming** | Divergent thinking benefits from focus but benefits from incubation breaks too |
| **Podcast/lecture learning** | Passive reception with active notes; lower ceiling for deep work gains |

---

## C-Tier — Minimal Deep Work Benefit (Shallow Work)

These tasks produce similar output whether done focused or distracted. Batch them; don't waste deep work slots on them.

| Task | Classification |
|---|---|
| Email / messages | Shallow — batch 2×/day |
| Scheduling / calendar | Shallow — delegate or batch |
| Status updates, reporting | Shallow — template + automate |
| Routine administrative forms | Shallow — eliminate or delegate |
| Social media | Shallow — time-box or eliminate |
| Passive re-reading of familiar material | Neither — better than social media, worse than active study |

---

## The "Deep Work Test" for Any Task

Ask these four questions:
1. Would an interruption require restarting from scratch? (Yes = deeper)
2. Does the quality of output scale with concentration time? (Yes = deeper)
3. Is this building a rare, valuable skill? (Yes = deeper)
4. Could this be done adequately while watching TV? (Yes = shallow)
